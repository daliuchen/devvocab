# ReadTrace Privacy Policy

Last updated: 2026-07-29

ReadTrace is a browser extension for saving technical words with their source page and original reading context.

## Data Stored Locally

ReadTrace stores the following data locally in your browser:

- Saved words and phrases.
- Original source sentences and nearby paragraph text.
- Page titles, URLs, canonical URLs, and domains.
- Source locators used to reopen and highlight saved words.
- Optional definitions and notes you enter.

## Data Collection

ReadTrace does not collect, transmit, sell, or share your saved words, notes, source pages, or browsing history with the developer or third parties.

ReadTrace does not use remote analytics.

ReadTrace does not require an account.

## Network Requests

The current version of ReadTrace does not call an external dictionary, AI provider, analytics service, or backend server.

## Browser Permissions

ReadTrace uses these permissions:

- `contextMenus`: Provides a right-click action for saving selected text.
- Host access for `http://*/*` and `https://*/*`: Lets the extension read the user's current text selection, capture local sentence context, and highlight saved words when reopening source pages.

ReadTrace only acts on pages where the user selects text, uses the context menu, opens the popup, or reopens a saved source.

## Data Export And Deletion

You can export saved data as JSON or Markdown from the ReadTrace library page.

You can delete saved occurrences or words from the ReadTrace library page.

Uninstalling the extension removes browser-managed local extension storage according to Chrome's extension storage behavior.
